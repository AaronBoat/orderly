# 🎥 X 视频本地处理工作流（Mac）

> 适用于：下载 X 视频 → 生成中文字幕 → 导出带硬字幕的 MP4  
> 工具链：`yt-dlp` + `whisper` + `ffmpeg`  
> 目标平台：X（Twitter），适配社媒运营、产品宣传、社区内容

---

## 🔧 1. 环境准备

### 安装依赖
```bash
# 安装 Homebrew（如未安装）
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# 安装 Python 和 FFmpeg
brew install python ffmpeg

# 安装 yt-dlp 和 Whisper
pip3 install yt-dlp openai-whisper
```

### 验证安装
```bash
yt-dlp --version    # 应显示版本号
whisper --help      # 应显示帮助信息
ffmpeg -version     # 应显示版本信息
```

> 💡 首次使用 `whisper` 时会自动下载模型（如 `small`），约 500MB。

---

## 📥 2. 下载 X 视频

```bash
# 进入项目目录
mkdir -p ~/Projects/orderly-videos
cd ~/Projects/orderly-videos

# 下载视频（替换为实际链接）
yt-dlp "https://x.com/username/status/1234567890"
```

✅ 输出：`Video Title [ID].mp4`

> ⚠️ 确保链接是 **推文页面 URL**，不是 `video.twimg.com/...mp4`

---

## 🗣️ 3. 生成中文字幕（.srt）

```bash
# 重命名简化（可选）
mv "Long Video Title [ID].mp4" demo.mp4

# 生成英文字幕（small 模型，高准确率）
whisper demo.mp4 --model small --language English --output_format srt
```
copilot 处理“按照区块链行业翻译成中英双语”

✅ 输出：`demo.mp4.srt`（标准 SRT 格式，带时间轴）

---

## 🔤 4. 烧录硬字幕（嵌入视频）

```bash
# 使用 ffmpeg 将字幕烧录进视频
ffmpeg -i demo.mp4 \
  -vf "subtitles=demo.mp4.srt:force_style='Fontsize=24,PrimaryColour=&HFFFFFF&,BackColour=&H000000&,BorderStyle=4,Alignment=2'" \
  -c:a copy \
  demo_subtitled.mp4
```

### 样式说明：
- `Fontsize=24`：适合 1080p
- `PrimaryColour=&HFFFFFF&`：白色文字
- `BackColour=&H000000&`：黑色背景（提升可读性）
- `Alignment=2`：居中对齐
- `BorderStyle=4`：带背景框（抗干扰）

> 💡 X 平台底部有 UI，建议字幕位置靠上（可在 `.srt` 中手动调整 Y 值，或用 DaVinci Resolve 微调）

## 📤 5. 导出为 X 优化格式

```bash
# 可选：进一步压缩以适配 X（控制码率 + 快速启动）
ffmpeg -i demo_subtitled.mp4 \
  -c:v libx264 -preset fast -crf 23 \
  -vf "scale=1920:1080,fps=30" \
  -c:a aac -b:a 320k \
  -movflags +faststart \
  orderly_final_for_x.mp4
```

✅ 最终文件：`orderly_final_for_x.mp4`（≤512MB，1080p，H.264/AAC）

## 🚀 6. 一键脚本（可选）

创建 `process-x.sh`：
```bash
#!/bin/zsh
URL="$1"
NAME="${2:-video}"

if [[ -z "$URL" ]]; then
  echo "用法: $0 <X视频链接> [输出名]"
  exit 1
fi

echo "📥 下载视频..."
yt-dlp -o "${NAME}.mp4" "$URL"

echo "🗣️ 生成中文字幕..."
whisper "${NAME}.mp4" --model small --language zh --output_format srt

echo "🔤 烧录字幕..."
ffmpeg -i "${NAME}.mp4" \
  -vf "subtitles=${NAME}.mp4.srt:force_style='Fontsize=24,PrimaryColour=&HFFFFFF&,BackColour=&H000000&,BorderStyle=4,Alignment=2'" \
  -c:a copy \
  "${NAME}_subtitled.mp4"

echo "✅ 完成！输出文件: ${NAME}_subtitled.mp4"
```

使用：
```bash
chmod +x process-x.sh
./process-x.sh "https://x.com/orderly_network/status/1234567890" orderly_demo
```

## 📌 注意事项

- **仅限公开视频**：尊重版权与隐私
- **字幕位置**：X 底部有播放控件，避免字幕放在最下方
- **文件大小**：X 限制 512MB，60 秒视频通常 <100MB
- **模型选择**：`small` 平衡速度与准确率；如需更快可用 `base`
