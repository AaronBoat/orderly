# Bot 测试和监控指南

## ✅ 已修复的问题

1. **多实例冲突** - 停止了所有重复的 Bot 实例
2. **消息转发失败** - 改进了转发逻辑，支持不同类型的媒体消息
3. **消息处理逻辑** - 更智能地判断是否需要翻译

## 🧪 测试步骤

### 1. 在源群组发送测试消息

在 **Orderly Discussion Channel** (源群组) 中发送以下类型的消息：

- ✅ 纯文本消息（会被翻译）
- ✅ 图片 + 文字说明（文字会被翻译）
- ✅ 只有图片无文字（会直接转发）
- ✅ 视频 + 文字说明（文字会被翻译）

### 2. 查看目标群组

检查 **Orderly中文官方社区** (目标群组) 是否收到：
- 翻译后的中文消息
- 保留了原有的图片/视频等媒体文件

### 3. 查看 Bot 日志

```bash
screen -r telegram-bot
```

应该看到类似的日志：
```
收到新消息 ID: xxxxx from Chat: -1002011191127
翻译成功 (尝试 1/3)
消息 xxxxx 翻译转发成功
```

**退出日志查看**（不停止 Bot）：
按 `Ctrl+A` 然后按 `D`

## 📊 监控命令

### 检查 Bot 状态
```bash

```

### 实时查看日志
```bash
screen -r telegram-bot
```

### 停止 Bot
```bash
screen -X -S telegram-bot quit
```

### 重启 Bot
```bash
screen -X -S telegram-bot quit
./start_bot.sh
```

## 🐛 常见问题排查

### Bot 没有反应
1. 检查 Bot 是否在运行：`./status.sh`
2. 查看日志：`screen -r telegram-bot`
3. 确认 Bot 在两个群组中都是管理员
4. 确认 Group Privacy 已关闭（@BotFather）

### 消息没有被翻译
1. 检查 Gemini API Key 是否有效：`python3 test_bot.py`
2. 查看日志中是否有翻译错误
3. 确认网络可以访问 Google 服务

### 消息重复发送
1. 停止所有 Bot 实例：`pkill -f "python.*main.py"`
2. 清理 screen 会话：`screen -X -S telegram-bot quit`
3. 重新启动：`./start_bot.sh`

## ⚙️ 配置优化建议

### 如果翻译速度慢
编辑 `config.yaml`：
```yaml
gemini:
  model_name: "gemini-2.5-flash"  # 最快的模型
```

### 如果想要更高质量的翻译
```yaml
gemini:
  model_name: "gemini-2.5-pro"  # 质量最好但较慢
```
